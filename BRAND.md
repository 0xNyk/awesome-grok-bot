## Role

Grok Bot is the Cursor product. Awesome Grok Bot is 0xNyk's independent open-source
directory for optional skills, plugins, MCP servers, and integrations around it.
This directory is not an official Cursor or xAI project.

The brand sells **curation + map**, not a chatbot.
